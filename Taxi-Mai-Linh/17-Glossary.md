# 17 — BẢNG THUẬT NGỮ

| Term | Meaning |
|---|---|
| Booking | Yêu cầu đặt xe |
| Trip | Chuyến đi thực tế phát sinh từ booking |
| Assignment | Quan hệ gán booking cho xe/tài xế, gồm offer và kết quả |
| Dispatch | Quy trình tìm, mời và gán xe |
| DIRECT | Xe/tài xế Mai Linh quản lý trực tiếp theo mô hình đã thống nhất |
| PARTNER | Xe/tài xế đối tác/hợp tác |
| Fleet type | DIRECT hoặc PARTNER |
| Booking channel | Kênh tiếp nhận HOTLINE/APP/WEB/API... |
| Candidate | Xe/tài xế đủ điều kiện nhận booking |
| Offer | Lời mời nhận booking có thời hạn |
| Control Tower | Màn hình điều hành gồm queue, map, KPI và alerts |
| GPS freshness | Độ mới của vị trí GPS |
| Tariff | Bảng/chính sách giá có version |
| Fare | Kết quả tính cước của trip |
| Payment | Giao dịch thu tiền |
| Ledger | Sổ ghi nhận tài chính có tham chiếu nguồn |
| Settlement | Quy trình đối soát và xác nhận công nợ/thanh toán |
| Policy snapshot | Bản chính sách/version áp dụng tại thời điểm nghiệp vụ |
| Exception queue | Hàng đợi cần xử lý thủ công/escalation |
| UAT | User Acceptance Testing |
| NFR | Non-Functional Requirement |
| ADR | Architecture Decision Record |
